📖 Как экспортировать аудио из видео

Для проверки громкости очень больших файлов (>4 ГБ) экспортируйте звук отдельно:

  • Adobe Premiere Pro: File → Export → Media → Format: Waveform Audio → Export
  • DaVinci Resolve: Deliver → Format: WAV → Audio Only → Render
  • Final Cut Pro: File → Share → Export File → Settings: Audio Only
  • Avid Media Composer: File → Output → Export to File → WAV/AIFF

Параметры экспорта: WAV, 48 kHz, 24-bit, Stereo (или 5.1 если многоканальный звук)
