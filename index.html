📖 Как экспортировать аудио из видео

Для проверки громкости очень больших файлов (>4 ГБ) экспортируйте звук отдельно:

  • Adobe Premiere Pro: File → Export → Media → Format: Waveform Audio
  • DaVinci Resolve: Deliver → Format: WAV → Audio Only → Render
  • Final Cut Pro: File → Share → Export File → Settings: Audio Only
  • Avid Media Composer: File → Output → Export to File → WAV/AIFF

Параметры экспорта: WAV, 48 kHz, 24-bit, Stereo

Аудиотесты

8 тестов
01
Интегральный уровень громкости и нормализация
Проверяет соответствие интегральной громкости целевому уровню по стандарту EBU R 128. Может выполнить нормализацию, если громкость отклоняется от заданного значения. Тест провален, если фактический уровень LUFS выходит за пределы допустимого отклонения.
Аудио
02
Параметры громкости
Проверяет сразу несколько параметров: диапазон громкости LRA, максимальные значения Short-term, Momentary, Sample Peak dBFS и True Peak dBTP. Результаты корректны только при отключённой нормализации.
Аудио
03
Тишина
Ищет полное отсутствие звука на всех дорожках или на дорожках, указанных маппингом. Тест провален, если тишина обнаружена хотя бы на одном канале. Пропускается, если длительность файла меньше порогового интервала.
Аудио
04
Перегрузка
Ищет плоские участки сигнала с амплитудой, близкой к максимальному уровню (clipping). Настраивается порог количества подряд идущих семплов на максимуме. Тест провален при обнаружении перегрузки хотя бы в одном канале.
Аудио
05
Несоответствие стерео / моносигнала
Определяет наличие моносигнала в стереопаре (L и R идентичны) или стереосигнала там, где ожидается моно. Работает только со стереопарами, настроенными в маппинге теста №01.
Аудио
06
Сдвиг аудиофаз
Выявляет смещение фазы одного канала стереопары относительно другого. В предельном случае — противофаза: суммарный сигнал равен нулю. Тест провален, если хотя бы в одной стереопаре найдены интервалы со сдвигом фаз.
Аудио
07
Тестовый сигнал
Ищет тестовый тональный сигнал заданной частоты (обычно 1 kHz) на всех дорожках или на дорожках по маппингу. Тест провален, если тестовый сигнал найден хотя бы в одном канале.
Аудио
08
Отсутствие аудиосигнала
Ищет сегменты, где все сэмплы заполнены нулями — то есть сигнала нет совсем (в отличие от теста «Тишина», который измеряет уровень громкости). Тест провален при обнаружении нулевых сегментов.
Аудио

Видеотесты

17 тестов
09
Артефакты потери данных
Выявляет артефакты потери данных в кадрах (хаотичные пиксели, повреждённые области). Тест провален, если артефакты обнаружены.
Видео
10
Артефакты потери данных в макроблоках
Более точная версия предыдущего теста: кадр разбивается на блоки 16×16 пикселей, и в каждом ищутся повреждения. Позволяет локализовать дефект внутри кадра.
Видео
11
Артефакты сжатия
Ищет дефекты, вызванные потерями при сжатии: блочность, размытие, ореолы. Тест провален, если интервалы с артефактами обнаружены.
Видео
12
Микропланы
Определяет серии одинаковых кадров, резко отличающихся от соседних (вспышки, заморозка). Использует классический алгоритм сравнения кадров.
Видео
13
Микропланы (алгоритмы машинного обучения)
Аналог теста №12, но использует ML-алгоритмы. Может обнаруживать более тонкие дефекты, незаметные классическому алгоритму.
Видео
14
Калибровочные таблицы
Ищет кадры с тестовыми таблицами в программном материале. Поддерживает разрешения от 720×576 до 4096×1716. Тест провален, если таблица обнаружена.
Видео
15
Стоп-кадры
Ищет последовательности полностью одинаковых кадров (заморозка видео). Отличается от микропланов тем, что ищет именно «зависание» без резкого изменения.
Видео
16
Чёрные кадры
Ищет кадры, представляющие собой полностью чёрное поле. Тест провален при обнаружении таких кадров. Может учитывать наличие аудиосигнала (опция «Учитывать наличие звука»).
Видео
17
Цветные кадры
Ищет кадры, заполненные однородным цветом во весь экран. Тест провален при обнаружении таких кадров.
Видео
18
Чёрные полосы по краям (каше)
Определяет тип и наличие чёрных полос: Letterbox (горизонтальные), Pillarbox (вертикальные), Windowbox (со всех сторон). Тест провален при обнаружении любого типа каше.
Видео
19
Гребёнка
Ищет дефект интерлейсинга — зазубренность краёв движущихся объектов, возникающую из-за несостыковки чётных и нечётных строк. Алгоритм сравнивает метрики между соседними кадрами.
Видео
20
Детектирование признаков чересстрочной развёртки
В отличие от «Гребёнки», объединяет отдельные дефектные кадры в сцены. Определяет порядок полей: TFF (верхнее первое) или BFF (нижнее первое). Выявляет тонкие дефекты, не всегда заметные глазу.
Видео
21
Уровень чёрного и белого
Ищет пиксели, чья яркостная компонента выходит за допустимый диапазон 16–235 (8-bit) или 63–941 (10-bit). По умолчанию допускается до 10% бракованных пикселей в кадре.
Видео
22
Уровень насыщенности
Моделирует работу вектороскопа: вычисляет границы корректной цветности и попиксельно проверяет каждый кадр. Пиксели вне допустимого gamut считаются бракованными.
Видео
23
Ошибки декодирования видео
Определяет ошибки, возникающие при декодировании отдельных кадров (AC EOB marker, Concealing bitstream errors и пр.). Тест провален, если найдены кадры с ошибками декодирования.
Видео
24
Gamut-ошибки
Проверяет выход цветовых компонент пикселей за границы «Preferred Min/Max» по стандарту EBU R 103. Применяется матрица BT.601 / BT.709 / BT.2020 в зависимости от разрешения.
Видео
25
Детектирование шума
Ищет кадры с чрезмерной зашумлённостью. Алгоритм работает по скользящему окну, поэтому возможны ложные срабатывания на высокодетализированных сценах (трава, рябь воды, звёздное небо).
Видео
78
Артефакты upconversion
Выявляет артефакты, возникающие при искусственном увеличении разрешения (upscale). Тест провален, если найдены интервалы с признаками неправильного масштабирования.
Видео
75
Цветные линии
Ищет горизонтальные полосы шириной 1–6 пикселей, чья насыщенность и яркость резко отличается от соседних строк. Тест провален при обнаружении таких линий хотя бы в одном кадре.
Видео
76
Уровень цветовых компонент
Аналог теста «Уровень чёрного и белого» для цветовых компонент U и V. Допустимый диапазон по умолчанию 16–240 (8-bit). Порог бракованных пикселей по умолчанию 1%.
Видео
74
Интегральная метрика качества
Агрегирует результаты нескольких тестов в единую числовую метрику: Артефакты сжатия, Шум, Микропланы, Таблицы, Стоп-кадры, Гребёнка, Уровень ЧБ, Насыщенность, Чёрные кадры. По умолчанию уровень важности «Низкий».
Видео

Тесты контейнера

9 тестов
26
Тип контейнера
Сравнивает фактический тип контейнера (из метаданных) с ожидаемым (из расширения файла). Для MXF тест пройден только если это MXF OP-1a.
Мета
27
Ошибки PS-контейнера
Специфичен для MPEG PS. Проверяет корректность заголовков всех пакетов и наличие кода окончания файла 00 00 01 B9. Пропускается для всех форматов, кроме PS.
Мета
28
Ошибки TS-контейнера
Специфичен для MPEG TS. Проверяет сервисную информацию: PAT, PMT, PCR, SDT, BAT, TDT, TOT, CAT, синхробайты, TEI, TSC и др. Каждая ошибка может быть настроена как критическая.
Мета
29
Целостность контейнера
Проверяет целостность контейнера по набору критериев (заголовок, partition pack, footer, MDAT-атом и пр.). Для каждого критерия можно отключить влияние на итоговый статус. Пропускается для TS/M2TS.
Мета
30
Ошибки непрерывности последовательности таймкодов
Извлекает таймкоды из файла и проверяет их непрерывность. Работает только с форматом XDCAM HD422 (MXF + MPEG-2 422P@HL).
Мета
31
Корректность заголовка
Проверяет параметр Title каждого потока файла на наличие только допустимых символов. Тест провален, если заголовок содержит запрещённые символы. Если Title отсутствует — тест пройден.
Мета
32
Конфигурация треков
Проверяет фактическое количество треков каждого типа (Видео, Аудио, Текст, Таймкод, Другое, Изображение, Меню) по заданным правилам. Также может проверять отсутствие треков с меткой Ancillary data.
Мета
62
Параметры MXF контейнера
Проверяет специфичные для MXF параметры: Format Version, Profile, Resolution, Wrapping Mode (FrameWrapped/ClipWrapped), Partitions State, Index Table, RIP Presence, Picture Essence Coding и др.
Мета
63
Профиль формата
Сравнивает фактический профиль контейнера с ожидаемым списком. Например: OP-1a для MXF. Тест провален, если фактическое значение не найдено в списке допустимых.
Мета

Метаданные аудио

8 тестов
33
Аудиокодек
Сравнивает фактический кодек каждой аудиодорожки с допустимым списком (PCM, AAC и др.). Тест провален, если хотя бы для одной дорожки кодек не совпал или не найден в метаданных.
Мета
34
Битрейт аудио
Сопоставляет фактический битрейт каждой аудиодорожки с заданным правилом (например, «= 1100 Кб/с»). Значение извлекается из метаданных.
Мета
50
Количество аудиоканалов в файле
Проверяет суммарное количество аудиоканалов во всём файле (сумма каналов по всем трекам). Тест провален, если фактическое число не соответствует правилу.
Мета
51
Количество аудиоканалов в треке
Проверяет количество каналов для каждого аудиотрека отдельно. Тест провален, если хотя бы у одного трека значение не соответствует правилу или параметр не найден.
Мета
52
Частота дискретизации аудио
Сравнивает частоту дискретизации каждой аудиодорожки с допустимым списком. Стандарт для вещания — 48 000 Гц. Тест провален при несоответствии хотя бы одной дорожки.
Мета
53
Битовая глубина аудио
Проверяет битность аудио каждой дорожки. Применимо только к PCM: для других кодеков тест пропускается. Стандарт вещания — 24-bit.
Мета
54
Схема каналов
Сравнивает фактическую схему каналов (L R, C L R Ls Rs LFE и др.) с допустимым списком для каждой аудиодорожки. Тест провален при несоответствии.
Мета
77
Проверка языковых тегов аудиодорожек
Извлекает языковые теги аудиодорожек и сравнивает с допустимыми значениями. Можно задать ожидаемые теги для конкретных дорожек и отдельно — для «остальных». Тест провален, если теги не найдены или не соответствуют.
Мета

Видеокодек

Мета

Мета
39
Количество кадров в секунду (FPS)
Сравнивает фактический FPS из метаданных с допустимым списком значений. Тест провален при несоответствии.
Мета
40
Битрейт видео (метаданные)
Сравнивает битрейт из метаданных видеодорожки с заданным диапазоном. Поддерживает только CBR (константный) битрейт.
Мета
41
Реальный битрейт видео
Вычисляет фактический битрейт путём обхода всех кадров и суммирования размеров пакетов. Более точен, чем значение из метаданных.
Мета
42
Тип развёртки
Сравнивает тип развёртки из метаданных (Progressive, Interlaced, PAFF) с ожидаемым. Тест провален при несоответствии.
Мета
43
Порядок полей
Проверяет последовательность полей (TFF — верхнее первое или BFF — нижнее первое) для чересстрочного видео. Пропускается для прогрессивного.
Мета
55
Битовая глубина видео
Сравнивает фактическую глубину цвета видеодорожки (8, 10, 12-bit) с допустимым значением.
Мета
67
Профиль и уровень формата
Проверяет параметр Format Profile видеодорожки. Например 4:2:2@High для MPEG-2 или High 4:4:4 Predictive@L4 для H.264.
Мета
65
Длительность видео
Сравнивает фактическую длительность видеодорожки с заданным правилом (например «= 120 секунд»). Тест провален при несоответствии.
Мета
66
Количество видеодорожек
Проверяет, что число видеодорожек соответствует заданному правилу (обычно «= 1»). Тест провален при несоответствии.
Мета
68
Длительность последнего кадра
Сравнивает длительность последнего кадра с заданным правилом. Можно также указать, что этот параметр должен отсутствовать в метаданных.
Мета
64
Типы кодирования кадров
Ищет нарушения в последовательности типов кадров I, P, B, S, SI, SP, BI. Для каждого типа задаётся правило проверки последовательности.
Мета
70
Метаданные GOP структуры
Определяет наличие регулярной GOP-структуры и вычисляет параметры M (интервал между P-кадрами) и N (интервал между I-кадрами). Тест провален, если структура не найдена или параметры не совпадают.
Мета
81
Соответствие битовой глубины в метаданных и в кадре
Сопоставляет битовую глубину из метаданных файла с фактической глубиной в каждом кадре. Выводит интервалы, где значения не совпадают.

Проверяет все найденные таймкоды в файле (MaterialTimecode, SourceTimecode, SmpteTcTimecode, DvSubcode) на соответствие ожидаемым значениям. Тест провален, если хотя бы один таймкод не совпадает или отсутствует.
